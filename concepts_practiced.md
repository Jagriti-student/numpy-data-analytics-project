# 🧠 Concepts I Practiced

## 1. NumPy Arrays

Learned how NumPy arrays can store numerical data efficiently and allow operations on multiple values at once.

## 2. Indexing and Slicing

Practiced accessing specific rows, columns, and sections of a 2D array.

## 3. Axis

One of the most important concepts I practiced was `axis`.

* `axis=0` → Perform operations column-wise
* `axis=1` → Perform operations row-wise

I used this to calculate subject-wise and student-wise averages.

## 4. Vectorized Operations

Instead of using loops, NumPy allows mathematical operations directly on arrays.

Example:

`students + 5`

This applies bonus marks to every value.

## 5. Boolean Indexing

Used conditions to filter students based on their performance.

Example:

`students[average > 80]`

## 6. Statistical Functions

Practiced:

* mean
* max
* min
* sum
* standard deviation

## 7. Reshaping

Learned how array dimensions can be changed using `reshape()` without changing the underlying data.

## 8. Combining Arrays

Practiced combining datasets using:

* `vstack()`
* `hstack()`
* `concatenate()`

## 9. Random Data

Used NumPy random functions to generate sample student datasets for experimentation.

---

## My Key Learning

The biggest thing I learned is that NumPy is not just a collection of functions. Its real power comes from performing operations efficiently on entire arrays without writing traditional loops.
