# 📊 NumPy Student Performance Analyzer

A hands-on data analysis project built using **Python and NumPy**.

## 🎯 Project Goal

I recently completed a NumPy one-shot tutorial, but instead of stopping at watching the concepts, I wanted to practice them by building something.

This project is my attempt to learn NumPy through implementation.

The goal is to analyze student performance data and use different NumPy operations to extract meaningful insights.

## 🚀 Features

* Create and work with NumPy arrays
* Analyze array properties
* Perform indexing and slicing
* Calculate statistical values
* Perform mathematical operations
* Apply boolean filtering
* Find top-performing students
* Perform subject-wise analysis
* Reshape and flatten arrays
* Combine arrays
* Generate random datasets

## 📚 NumPy Concepts Practiced

| Concept                 | Usage                                  |
| ----------------------- | -------------------------------------- |
| Arrays                  | Store student marks                    |
| Shape & Dimensions      | Understand dataset structure           |
| Indexing                | Access student records                 |
| Slicing                 | Select specific data                   |
| Mathematical Operations | Modify marks                           |
| Broadcasting            | Apply operations efficiently           |
| Mean & Statistics       | Analyze performance                    |
| Axis                    | Subject-wise and student-wise analysis |
| Boolean Indexing        | Filter students                        |
| argmax                  | Find top performer                     |
| Reshape                 | Transform array structure              |
| vstack / concatenate    | Add new data                           |
| Random                  | Generate sample datasets               |
